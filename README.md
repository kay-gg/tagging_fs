# Tagging Filesystem Library
Library used in my other tagging-project projects, [tags-frontend](https://github.com/kay-gg/tags-frontend), and [tags-backend](https://github.com/kay-gg/tags-backend)

My main goal when developing this library was to practice Test Driven Development, and I achieved a 96% test coverage according to [tarpaulin](https://github.com/xd009642/tarpaulin), a code coverage reporting tool. The report is included in the repository.
